88341 Imhchem/imcytchm each add antb

Pathology & Lab +Add-on

Also known as: immunochemistry additional antibody add-on, IHC each add-on antibody

Immunohistochemistry or immunocytochemistry for each additional antibody beyond the first antibody applied to tissue.

Clinical Context

Add-on code when multiple antibodies are needed for diagnosis; each antibody requires separate processing and is counted separately.
