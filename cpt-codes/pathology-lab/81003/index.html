81003 Urinalysis auto without scope

Pathology & Lab

Also known as: automated urinalysis only, automated dipstick

Urinalysis, automated without microscope examination. Uses automated analyzer for chemical components only, no microscopy.

In Plain Language

machine urine chemistry test

Clinical Context

Used in automated laboratory settings when chemical analysis is sufficient and microscopy is not indicated.
