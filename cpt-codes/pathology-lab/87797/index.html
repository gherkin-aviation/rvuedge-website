87797 Detection agent not otherwise specified dna dir

Pathology & Lab

Also known as: Not otherwise specified pathogen test, unspecified agent detection

Unspecified infectious agent nucleic acid detection using direct probe technique without amplification. Detects unspecified pathogen.

Clinical Context

Used when direct probe detection is performed for infectious agents not otherwise specified in standard test codes.
