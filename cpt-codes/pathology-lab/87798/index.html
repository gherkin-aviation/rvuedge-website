87798 Detection agent not otherwise specified dna amp

Pathology & Lab

Also known as: Not otherwise specified amplified test, unspecified agent amplification

Unspecified infectious agent nucleic acid detection using amplified probe technique. Detects unspecified pathogen with amplification.

Clinical Context

Used when amplified probe detection is performed for infectious agents not otherwise specified in standard test codes.
