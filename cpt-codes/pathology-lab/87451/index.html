87451 Polyvalent mult org each ag ia

Pathology & Lab

Also known as: polyvalent antigen panel, multiplex organism antigen, multi-organism IA

Detection of multiple organism antigens using multiplexed immunoassay methodology with identification of each organism tested.

In Plain Language

multiple organism antigen test

Clinical Context

Simultaneous detection of multiple pathogens using multiplex immunoassay. Useful for rapid screening when multiple organisms are suspected.
