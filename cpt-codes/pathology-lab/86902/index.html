86902 Blood type antigen donor each

Pathology & Lab

Also known as: Donor antigen typing, Extended donor typing, Antigen phenotyping

Serologic blood typing to identify antigen status on donor red blood cells for each antigen. Donor phenotyping for transfusion.

In Plain Language

Donor blood type detailed test; Blood compatibility testing

Clinical Context

Used to determine donor red cell antigen profile to select appropriately matched blood for transfusion, particularly in chronically transfused patients.

RVU Information
