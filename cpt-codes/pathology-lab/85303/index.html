85303 Clot inhibit prot c activity

Pathology & Lab

Also known as: protein C activity, functional protein C

Assay of protein C functional activity using chromogenic substrate or clotting methodology to measure anticoagulant and fibrinolytic activity of activated protein C.

In Plain Language

anticlotting protein C function; protein C activity test

Clinical Context

Evaluates protein C deficiency in thrombophilia and warfarin therapy, detects protein C inhibitors, and assesses activated protein C resistance.

RVU Information
