01999 Unlisted anesthesia procedure

Anesthesia

Also known as: unlisted anesthesia, miscellaneous anesthesia

Unlisted anesthesia procedure. This code is used for anesthetic services not otherwise classified or represented by a more specific CPT code.

In Plain Language

Special sleep medication not in standard list; Custom anesthesia care

Clinical Context

Used when an anesthetic procedure does not fit into any existing category. Requires documentation explaining the nature of the anesthetic service provided. Common for novel or unusual anesthetic techniques.

RVU Information

CPT 01999 does not have a physician work RVU assigned by CMS. Anesthesia codes use a base unit + time unit system rather than standard RVUs. Contact your payer for the anesthesia conversion factor.

Billing & Documentation

Anesthesia codes are billed using base units plus time units. One time unit typically equals 15 minutes of anesthesia time. Document start and stop times, patient status (P1-P6), and any qualifying circumstances. Modifiers AA, QK, QX, or QY indicate the provider arrangement.
