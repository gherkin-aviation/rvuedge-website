T2002 N-et; per diem

Other HCPCS

Also known as: non-emergency transport per diem, daily transport service, transport daily rate

Non-emergency transportation service provided on a per-diem or daily rate basis.

In Plain Language

daily transportation service; transport day rate

Clinical Context

Non-emergency transportation services provided on daily basis for patients requiring routine medical transport.

RVU Information

CPT T2002 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
