T1020 Personal care ser per diem

Other HCPCS

Also known as: personal care per diem, daily personal care, personal care day rate

Personal care services provided on a per-diem basis for assistance with activities of daily living.

In Plain Language

personal care help; daily living assistance

Clinical Context

Non-medical daily assistance with activities of daily living for individuals with functional limitations or disabilities.

RVU Information

CPT T1020 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
