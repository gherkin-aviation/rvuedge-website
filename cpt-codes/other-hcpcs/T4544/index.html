T4544 Adlt disp und/pull on abv xl

Other HCPCS

Also known as: Adult pull-on XXL, Large capacity pull-up

Adult disposable pull-on or underpants, above extra-large size. Extra-capacity disposable pull-on incontinence garment for adults in above extra-large sizing.

In Plain Language

Extra-large pull-up for adults; High-capacity adult pull-on brief

Clinical Context

Medicaid-covered disposable pull-on incontinence brief in above extra-large sizing offering ease of application for larger individuals with incontinence.

RVU Information

CPT T4544 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
