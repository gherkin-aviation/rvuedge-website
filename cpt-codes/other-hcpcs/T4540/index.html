T4540 Reusable underpad chair size

Other HCPCS

Also known as: Chair pad, Furniture protector

Reusable underpad, chair size. Washable protective underpad for placement on chairs or furniture providing absorbent protection.

In Plain Language

Washable chair protection pad; Reusable furniture pad

Clinical Context

Medicaid-covered washable chair-sized underpad protecting furniture from incontinence moisture, suitable for repeated use in various seating areas.

RVU Information

CPT T4540 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
