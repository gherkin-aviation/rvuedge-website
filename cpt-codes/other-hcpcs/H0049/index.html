H0049 Alcohol/drug screening

Other HCPCS

Also known as: substance abuse screening, drug screening, A/D screening

Alcohol and/or drug abuse screening services using standardized assessment tools.

In Plain Language

substance use test; addiction screening

Clinical Context

Used for brief screening procedures identifying individuals at risk for substance abuse to determine need for comprehensive assessment and treatment.

RVU Information

CPT H0049 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
