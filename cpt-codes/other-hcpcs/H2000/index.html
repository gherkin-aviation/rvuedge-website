H2000 Complicated multidisipln evaluation

Other HCPCS

Also known as: multidisciplinary eval, team assessment, comprehensive evaluation

Comprehensive multidisciplinary behavioral health evaluation and assessment by multiple specialists.

In Plain Language

team mental health evaluation; comprehensive psychological assessment

Clinical Context

Used for comprehensive behavioral health evaluation conducted by a multidisciplinary team addressing psychiatric, psychological, medical, and social factors.

RVU Information

CPT H2000 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
