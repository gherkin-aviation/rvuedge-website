H2020 Therapy behav service, per diem

Other HCPCS

Also known as: behavioral services, behavior therapy, therapeutic program

Therapeutic behavioral services addressing maladaptive behaviors and promoting positive behavior change on a per diem basis.

In Plain Language

daily behavior therapy; behavioral support program

Clinical Context

Used for daily therapeutic behavioral programs addressing maladaptive behaviors and supporting positive behavioral change.

RVU Information

CPT H2020 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
