H2031 Mh clubhouse service, per diem

Other HCPCS

Also known as: clubhouse service, psychiatric clubhouse per diem

Mental health clubhouse service provided on a per diem basis, including daily psychosocial rehabilitation and community engagement.

In Plain Language

daily mental health support program; day program for mental illness

Clinical Context

Psychosocial clubhouse model for serious mental illness, billed per calendar day. Includes vocational, social, and recreational activities.

RVU Information

CPT H2031 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
