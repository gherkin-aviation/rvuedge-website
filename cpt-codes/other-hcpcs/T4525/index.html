T4525 Adult size pull-on sm

Other HCPCS

Also known as: Adult pull-on small, Pull-up diaper small

Adult size pull-on incontinence garment, small size. Disposable pull-on style incontinence brief for adults in small dimensions requiring minimal changing effort.

In Plain Language

Adult pull-up incontinence product, small; Easy-on incontinence brief

Clinical Context

Medicaid-covered disposable pull-on incontinence brief in small adult sizing offering ease of application and removal for individuals with incontinence.

RVU Information

CPT T4525 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
