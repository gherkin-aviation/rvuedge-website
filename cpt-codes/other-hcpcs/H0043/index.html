H0043 Supported housing, per diem

Other HCPCS

Also known as: supported housing, housing services, housing support

Supported housing services including stable housing with community support on a per diem basis.

In Plain Language

safe housing support; community housing with help

Clinical Context

Used for supported housing programs providing stable housing combined with ongoing community support services for individuals with behavioral health conditions.

RVU Information

CPT H0043 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
