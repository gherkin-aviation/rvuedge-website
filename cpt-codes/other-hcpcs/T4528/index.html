T4528 Adult size pull-on xl

Other HCPCS

Also known as: Adult pull-on XL, Pull-up diaper XL

Adult size pull-on incontinence garment, extra-large size. Disposable pull-on style incontinence brief for adults in extra-large dimensions.

In Plain Language

Adult pull-up incontinence product, extra-large; Easy-on XL brief

Clinical Context

Medicaid-covered disposable pull-on incontinence brief in extra-large adult sizing offering ease of application and removal for larger individuals with incontinence.

RVU Information

CPT T4528 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
