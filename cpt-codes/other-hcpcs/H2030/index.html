H2030 Mh clubhouse service, per 15 minutes

Other HCPCS

Also known as: clubhouse service, psychiatric clubhouse

Mental health clubhouse service provided for 15-minute increments, a psychosocial rehabilitation program for individuals with serious mental illness.

In Plain Language

day program for mental health support; social activity program for mental illness

Clinical Context

Clubhouse model provides vocational training, social activities, and peer support for individuals with serious mental illness. Billed in 15-minute units.

RVU Information

CPT H2030 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
