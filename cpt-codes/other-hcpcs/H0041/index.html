H0041 Fos c chld non-ther per diem

Other HCPCS

Also known as: foster care, placement services, out-of-home care

Foster care services for children including non-therapeutic foster placement on a per diem basis.

In Plain Language

foster home placement; temporary foster care

Clinical Context

Used for foster care placement and support services for children in the child welfare system providing safe out-of-home placement when family care is not available.

RVU Information

CPT H0041 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
