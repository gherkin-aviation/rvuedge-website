T1014 Telehealth transmit, per minutes

Other HCPCS

Also known as: telehealth transmission, remote monitoring, telemedicine data transmission

Telehealth transmission of medical information, images, or data for remote patient monitoring or consultation.

In Plain Language

video doctor visit; remote health monitoring; telehealth transmission

Clinical Context

Technology services supporting remote delivery of healthcare including data transmission for store-and-forward telemedicine and real-time monitoring.

RVU Information

CPT T1014 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
