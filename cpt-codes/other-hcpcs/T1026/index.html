T1026 Pediatric compr care pkg, per hour

Other HCPCS

Also known as: pediatric care package hourly, hourly pediatric care, pediatric intensive care

Pediatric comprehensive care package providing bundled health services on a per-hour basis for intensive pediatric care.

In Plain Language

hourly children's care service; intensive pediatric care

Clinical Context

Intensive hourly comprehensive care services for children with complex medical needs requiring more intensive support than daily services.

RVU Information

CPT T1026 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
