H1005 Prenatalcare enhanced srv pk

Other HCPCS

Also known as: comprehensive prenatal, enhanced services, prenatal package

Prenatal care services enhanced service package including comprehensive support addressing medical, behavioral, and social needs.

In Plain Language

full pregnancy care package; comprehensive pregnancy support

Clinical Context

Used for comprehensive enhanced prenatal care packages combining medical management, behavioral health, education, and social support services.

RVU Information

CPT H1005 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
