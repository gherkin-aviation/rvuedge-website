H0047 Alcohol/drug abuse service not otherwise specified

Other HCPCS

Also known as: substance abuse services, addiction services, drug services

Alcohol and/or drug abuse services not elsewhere specified covering miscellaneous substance abuse interventions and support services.

In Plain Language

addiction help; substance abuse support

Clinical Context

Used as a catch-all code for substance abuse services not otherwise categorized including various treatment interventions and recovery support.

RVU Information

CPT H0047 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
