T1028 Home environment assessment

Other HCPCS

Also known as: home safety assessment, environmental assessment, home evaluation

Home environment assessment evaluating safety, accessibility, and suitability for patient care delivery.

In Plain Language

home safety check; home care readiness assessment

Clinical Context

Comprehensive evaluation of home environment for safety hazards, accessibility barriers, and readiness for medical care delivery.

RVU Information

CPT T1028 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
