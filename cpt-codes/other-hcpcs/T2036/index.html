T2036 Camp overnite waiver/session

Other HCPCS

Also known as: Camp services, Overnight camp

Overnight camping or overnight residential program services under waiver, billed per session. Recreation and skill-building activities in overnight residential camping settings.

In Plain Language

Overnight camping experience; Residential recreational program

Clinical Context

Waiver-funded overnight recreational camping programs providing social interaction, skill development, and community integration experiences for individuals with developmental disabilities.

RVU Information

CPT T2036 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
