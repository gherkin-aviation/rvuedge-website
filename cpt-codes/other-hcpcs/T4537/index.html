T4537 Reusable underpad bed size

Other HCPCS

Also known as: Bed pad, Mattress protector

Reusable underpad, bed size. Washable protective underpad for placement on beds providing absorbent protection for bedding.

In Plain Language

Washable bed protection pad; Reusable mattress protector

Clinical Context

Medicaid-covered washable bed-sized underpad protecting mattresses and bedding from incontinence moisture, suitable for repeated use.

RVU Information

CPT T4537 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
