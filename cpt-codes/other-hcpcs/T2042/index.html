T2042 Hospice routine home care

Other HCPCS

Also known as: Hospice home care, Routine hospice

Hospice routine home care. Standard daily hospice services including nursing, aide services, medical supplies, and comfort-focused care in the patient's home.

In Plain Language

At-home end-of-life comfort care; Daily hospice support at home

Clinical Context

Medicare/Medicaid reimbursed daily hospice care in home settings for terminally ill patients, including nursing, personal care, medications, and spiritual/psychological support.

RVU Information

CPT T2042 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
