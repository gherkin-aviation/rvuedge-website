H2018 Psysoc rehabilitation service, per diem

Other HCPCS

Also known as: psychosocial rehabilitation, PSR, rehabilitation program

Psychosocial rehabilitation services addressing social, vocational, and functional recovery on a per diem basis.

In Plain Language

mental health rehabilitation program; daily recovery services

Clinical Context

Used for daily psychosocial rehabilitation programs supporting recovery and integration for individuals with serious mental illness.

RVU Information

CPT H2018 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
