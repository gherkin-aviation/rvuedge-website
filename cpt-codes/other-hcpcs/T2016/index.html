T2016 Habil res waiver per diem

Other HCPCS

Also known as: Hab residential services, Residential habilitation

Habilitation residential services under waiver, billed per diem. Support services in a residential setting to develop or maintain functional abilities and community integration skills.

In Plain Language

Daily living support in a residence; Residential skills development

Clinical Context

Daily per diem waiver funding for residential habilitation services enabling individuals with developmental disabilities to live in community settings with appropriate skill development and daily support.

RVU Information

CPT T2016 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
