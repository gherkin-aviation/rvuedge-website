T1030 Rn home care per diem

Other HCPCS

Also known as: RN home care per diem, home nursing per diem, nurse home visit

Registered nurse home care services provided on a per-diem basis in patient's home.

In Plain Language

home nurse visit; home nursing care

Clinical Context

Skilled nursing care provided in home setting including assessment, wound care, medication management, and disease monitoring.

RVU Information

CPT T1030 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

This HCPCS code requires documentation of medical necessity and a valid physician order. Coverage and reimbursement policies vary by payer. Check with the specific insurer for prior authorization requirements.
