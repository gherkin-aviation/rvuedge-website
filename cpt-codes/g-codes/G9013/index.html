G9013 Esrd demo bundle level i

G Codes

Also known as: ESRD demo level I, ESRD bundle services beginning

Performance measure code for End-Stage Renal Disease (ESRD) demonstration bundle services at level I intensity.

In Plain Language

Medicare ESRD payment program at basic level; kidney disease demonstration project level 1

Clinical Context

Billing code under Medicare ESRD demonstration models (such as ESRD Seamless Care Organization) for level I patient complexity or services.

RVU Information

CPT G9013 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation
