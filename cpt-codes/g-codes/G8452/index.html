G8452 Pt with abnormal lvef b-bloc no prescription

G Codes

Also known as: no beta blocker given, LVEF untreated, beta blocker not prescribed

Documentation indicator that patient with abnormal left ventricular ejection fraction did not receive beta-blocker prescription without documented reason.

In Plain Language

Heart patient not on beta blocker; Weak heart not treated with beta blocker

Clinical Context

Used to document instances where patients with reduced ejection fraction did not receive beta-blocker therapy without clear justification.

RVU Information

CPT G8452 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation
