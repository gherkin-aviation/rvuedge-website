G8880 Sen lym p node biop not perf

G Codes

Also known as: sentinel node biopsy not done, SLNB not performed

Performance measure indicating sentinel lymph node biopsy was not performed in patient with documented clinical reasons.

In Plain Language

lymph node was not biopsied; sentinel node biopsy was not necessary

Clinical Context

Documents appropriate exclusion from sentinel lymph node biopsy such as in clinical Stage 0 disease, distant metastasis, or prior axillary surgery.

RVU Information

CPT G8880 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation
