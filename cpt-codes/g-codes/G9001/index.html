G9001 Mccd, initial rate

G Codes

Also known as: chronic care management initial, CCM services initial rate

Performance measure code for chronic care management services at initial rate for patients enrolled in Medicare-covered chronic care management program.

In Plain Language

doctor's fee for managing chronic disease starting visit; initial chronic disease management billing code

Clinical Context

Billing code for Medicare chronic care management (CCM) services at the initial establishment rate for high-risk patients with two or more chronic conditions.

RVU Information

CPT G9001 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

G-codes are CMS-specific HCPCS codes for services not covered by standard CPT. Documentation requirements follow the same standards as the equivalent CPT service. Check Medicare LCD/NCD policies for coverage criteria.
