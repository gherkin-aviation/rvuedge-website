G0435 Oral hiv-1/hiv-2 screening

G Codes

Also known as: oral HIV test, saliva HIV screening, rapid oral test

Oral fluid-based HIV-1 and HIV-2 screening test using saliva collection for non-invasive antibody detection.

In Plain Language

spit HIV test; oral swab AIDS test

Clinical Context

Non-invasive HIV screening using oral mucosal transudate collected from mouth for antibody detection.
