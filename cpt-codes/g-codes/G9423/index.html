G9423 Medial reas report no histo type

G Codes

Also known as: histology omission reason, pathology limitation documented

Medical reason documented for not including histologic type in non-lung cancer pathology report.

In Plain Language

valid reason for incomplete cancer cell type report; medical reason for missing pathology detail

Clinical Context

Quality measure exception when non-lung cancer pathology report does not include histologic type but physician provides documented clinical justification.

RVU Information

CPT G9423 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation
