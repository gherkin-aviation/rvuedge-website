G9053 Onc expectant management pt

G Codes

Also known as: active surveillance, expectant management, watchful waiting

Performance measure code for oncology practice expectant management of cancer patient with observation without active treatment.

In Plain Language

cancer is being watched without immediate treatment; monitoring without active cancer treatment

Clinical Context

Billing code for oncology services involving expectant management (active surveillance) approach for selected cancer patients.

RVU Information

CPT G9053 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
