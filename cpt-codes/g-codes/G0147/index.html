G0147 Scr c/v cyto, automated sys

G Codes

Also known as: automated cytology screening, computer-assisted screening

Cervical and vaginal cytology screening using automated system without physician review, providing rapid initial screening classification.

In Plain Language

Computer screening of cervical cells; Automated Pap test

Clinical Context

Cytology screening using FDA-approved automated detection systems for initial cell classification. May include reflex to physician review for abnormal findings.

RVU Information

CPT G0147 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation
