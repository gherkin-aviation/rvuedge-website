G2202 No rsn no brief couns

G Codes

Also known as: counseling not done, intervention deferred, no ETOH counseling

Documentation indicator that brief counseling for unhealthy alcohol use was not provided, with documented reason justifying the omission.

In Plain Language

Alcohol counseling was not given with reason; Brief intervention not performed

Clinical Context

Used to document intentional non-provision of brief intervention when clinical or patient-specific reasons justify omission from quality measures.

RVU Information

CPT G2202 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

G-codes are CMS-specific HCPCS codes for services not covered by standard CPT. Documentation requirements follow the same standards as the equivalent CPT service. Check Medicare LCD/NCD policies for coverage criteria.

How This Code Compares
