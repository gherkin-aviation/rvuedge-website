36592 Collect blood from picc

Surgery

Also known as: PICC draw, PICC blood draw, blood collection from PICC

Collection of blood specimen from a peripherally inserted central catheter (PICC).

In Plain Language

drawing blood through a PICC line

Clinical Context

Used for routine or urgent blood draws from PICCs, reducing need for additional venipunctures in patients with difficult venous access.

RVU Information

CPT 36592 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
