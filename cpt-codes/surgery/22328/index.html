22328 Treat each add spine fracture

Surgery +Add-on

Also known as: additional vertebral fracture fixation, per additional level vertebral fixation

Open treatment of vertebral fracture, each additional vertebra. Each additional vertebra requiring surgical fixation beyond the first vertebra in multilevel fracture management.

Clinical Context

Used as add-on code for each additional vertebra requiring surgical fixation in multilevel vertebral fracture treatment. Appended to primary vertebral fracture fixation codes.
