64902 Nerve graft add-on

Surgery +Add-on

Also known as: second additional nerve graft

Add-on code for additional nerve graft segments or additional nerve branches beyond the first add-on nerve graft in the same operative session.

Clinical Context

Used when more than one additional nerve branch requires grafting beyond the primary nerve graft. Each additional graft after the first is coded with this code.
