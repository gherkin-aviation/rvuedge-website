63044 Laminotomy additional lumbar

Surgery +Add-on

Also known as: additional lumbar laminotomy, lumbar multilevel add-on

Laminotomy with or without discectomy in lumbar spine for each additional segment. Add-on code to primary lumbar procedure.

Clinical Context

Used as add-on code for each additional lumbar segment treated beyond the first.
