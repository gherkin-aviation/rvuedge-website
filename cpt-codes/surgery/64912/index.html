64912 Nerve repair with nerve algrft first

Surgery Global 90d

Also known as: allograft repair first, processed nerve first graft

Surgical repair of a nerve injury using processed nerve allograft for the first graft in a series of multiple allografts required for extensive nerve gaps.

Clinical Context

Used when extensive nerve gaps require multiple allograft segments. Code 64912 represents the first graft, with 64913 for each additional segment.
