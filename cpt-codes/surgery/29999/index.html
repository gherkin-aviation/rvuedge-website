29999 Unlisted procedures arthroscopy

Surgery

Also known as: unlisted arthroscopy, misc arthroscopy, arthroscopy unspecified

Unlisted or miscellaneous arthroscopic procedure performed by endoscopy, used to report arthroscopic interventions that do not have a specific corresponding CPT code.

In Plain Language

arthroscopy procedure not otherwise listed

Clinical Context

Reported when performing an arthroscopic procedure without a corresponding specific code; requires detailed documentation and may require special approval or payer authorization.

RVU Information

CPT 29999 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.

How This Code Compares
