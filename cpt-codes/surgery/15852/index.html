15852 Dressing change not for burn

Surgery Global 0d

Also known as: dressing change, wound dressing

Dressing change for non-burn wounds performed as a separately billable procedure, typically for complex or infected wounds requiring frequent management.

In Plain Language

Wound bandage change; Wound care management

Clinical Context

Billed separately when wound dressing changes are provided in an operative or hospital setting, particularly for complex wounds, infection management, or post-operative monitoring.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. This code has a 0-day global period, meaning pre- and post-operative E&M visits are billable separately on the same day. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
