38999 Unlistd procedures hemic/lymphtc sys

Surgery

Also known as: unlisted hemic procedure, unlisted lymphatic procedure

Unlisted surgical procedure on the hemic system (blood-forming organs) or lymphatic system. Used when a specific procedure code is not available in the CPT coding system.

In Plain Language

blood or lymph system surgery not otherwise coded

Clinical Context

Used for novel, experimental, or uncommon surgical procedures on the spleen, lymph nodes, or bone marrow that do not have specific CPT codes. Requires documentation of procedure details.

RVU Information

CPT 38999 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
