15018 application skn cll ssp f/n/g/hf each

Surgery +Add-on

Also known as: cell spray additional specialized, face/neck spray add-on

Application of autologous cultured skin cells via spray technique to face, neck, genitals, hands, or feet, each additional area. Add-on for multiple specialized regions.

In Plain Language

spraying cells on more sensitive areas; additional specialized region coverage

Clinical Context

Used when multiple specialized anatomical areas require cultured cell application such as combined facial and hand injury burns.

RVU Information

CPT 15018 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
