15012 Hrv skn cll ssp agrft each add

Surgery +Add-on

Also known as: cell suspension graft additional, spray graft add-on

Harvesting of skin cells via suspension technique for autologous graft, each additional 25 square centimeters beyond the first. Add-on code for extended coverage.

In Plain Language

additional area of cell collection; extra coverage cells

Clinical Context

Used when initial first 25 square centimeters is insufficient and additional donor cells are harvested to expand coverage area for transplantation.

RVU Information

CPT 15012 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
