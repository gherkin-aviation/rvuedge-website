Surgery

Unlisted procedural code for forearm, wrist, and hand procedures not specified by another code. Used when a specific code is not available.

In Plain Language

Clinical Context

Used when a procedure is performed on the forearm, wrist, or hand that does not have a more specific CPT code. Requires detailed operative note and clinical documentation.

RVU Information

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
