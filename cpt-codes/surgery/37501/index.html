Clinical Context

Used when a novel or unusual endovascular procedure does not fit standard code descriptions. Requires detailed operative documentation.

RVU Information

CPT 37501 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
