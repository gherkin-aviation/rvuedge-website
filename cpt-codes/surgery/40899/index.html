40899 Unlisted procedures vestibule mouth

Surgery

Also known as: unlisted mouth surgery, vestibule unlisted procedure, oral vestibule procedure

Unlisted procedure code for any surgical procedure on the oral vestibule and adjacent mouth structures not described by another CPT code.

In Plain Language

other mouth surgery; unlisted oral procedure; mouth surgery not otherwise listed

Clinical Context

Used when a specific surgical procedure on the oral vestibule, lips, or adjacent mouth structures is performed but no specific CPT code exists for that procedure. Requires documentation and justification.

RVU Information

CPT 40899 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
