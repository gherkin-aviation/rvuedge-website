64421 Njx aa and/or strd ntrcost nerve each

Surgery +Add-on

Also known as: additional intercostal nerve block, intercostal extension

Injection of anesthetic and/or steroid into intercostal nerve, each additional injection. Add-on code for injecting additional intercostal nerves.

Clinical Context

Applied when intercostal nerve blocks are performed at multiple rib levels.
