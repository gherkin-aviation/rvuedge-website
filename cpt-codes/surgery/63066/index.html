63066 Decompress spine cord add-on

Surgery +Add-on

Also known as: additional decompression extension, multi-level extension

Decompression of the spinal cord, add-on code for each additional segment when performing thoracic or combined decompression. Used to code additional levels beyond the primary decompression site.

In Plain Language

additional segment pressure relief

Clinical Context

Applied when thoracic or combined region spinal cord decompression requires extending to multiple vertebral levels.
