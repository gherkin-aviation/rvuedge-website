38900 Io map of sent lymph node

Surgery

Also known as: SLNB, sentinel node mapping, IO map

Intraoperative mapping of sentinel lymph node using radioisotope or fluorescent tracer during surgical excision. This technique identifies the first lymph node that drains from a tumor site to assess lymphatic spread.

In Plain Language

mapping the first lymph node to check for cancer spread; testing lymph nodes near cancer

Clinical Context

Essential in breast cancer surgery, melanoma, head and neck cancers to determine staging and extent of lymph node dissection needed. Helps avoid unnecessary removal of multiple lymph nodes.
