47579 Unlisted laps procedures biliary trc

Surgery

Also known as: Unlisted laparoscopic biliary procedure

Unlisted laparoscopic procedure code for procedures of the biliary tract performed through minimally invasive approach not explicitly defined by other CPT codes.

In Plain Language

Other laparoscopic gallbladder or bile duct surgery

Clinical Context

Used for innovative or rare laparoscopic biliary procedures. Requires documentation of procedure performed and physician work.

RVU Information

CPT 47579 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
