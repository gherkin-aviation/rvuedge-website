11201 removal skin tags each additional 10

Surgery +Add-on

Also known as: additional skin tag removal, skin tags each add-on

Removal of skin tags for each additional 10 lesions or part thereof. This add-on code extends beyond the initial 15 tags covered in 11200.

Clinical Context

Applied when patient has multiple skin tags (greater than 15) requiring removal in single session. Each additional 10 tags or portion thereof uses this add-on.
