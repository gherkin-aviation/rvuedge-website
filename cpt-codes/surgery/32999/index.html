32999 Unlisted procedures lungs & pleura

Surgery

Also known as: unlisted pulmonary procedure, unlisted thoracic surgery, unspecified lung operation

Unlisted procedure code for operations on the lungs and pleura not defined by a specific CPT code. Used when no other code adequately describes the procedure performed.

In Plain Language

procedure on lungs not listed in codes

Clinical Context

Placeholder code requiring detailed operative description and supporting documentation. Used to ensure proper billing for innovative or rarely performed lung and pleural procedures.

RVU Information

CPT 32999 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
