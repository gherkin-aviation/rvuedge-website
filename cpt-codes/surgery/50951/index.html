50951 Endoscopy of ureter

Surgery Global 0d

Also known as: ureteroscopy, ureteral endoscopy, diagnostic ureteroscopy

Endoscopy of ureter with visualization of the ureteral lumen via ureteroscope, diagnostic procedure to identify pathology.

In Plain Language

camera examination of the ureter

Clinical Context

Diagnostic procedure for hematuria, suspected stone, stricture, or mass evaluation. Zero global days indicates minimal post-operative care.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. This code has a 0-day global period, meaning pre- and post-operative E&M visits are billable separately on the same day. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
