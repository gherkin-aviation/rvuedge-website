63043 Laminotomy additional cervical

Surgery +Add-on

Also known as: additional cervical laminotomy, cervical multilevel add-on

Laminotomy with or without discectomy in cervical spine for each additional segment. Add-on code to primary cervical procedure.

Clinical Context

Used as add-on code for each additional cervical segment treated beyond the first.
