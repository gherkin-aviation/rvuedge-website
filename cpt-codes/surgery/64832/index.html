64832 Repair nerve add-on

Surgery +Add-on

Also known as: additional digit nerve repair

Add-on code for repair of one or more additional digit nerves in the same operative session as a primary digital nerve repair.

In Plain Language

repair of additional finger/toe nerves

Clinical Context

Used when multiple digits have nerve injuries requiring repair. Each additional digit nerve repair is coded separately with this add-on code.
