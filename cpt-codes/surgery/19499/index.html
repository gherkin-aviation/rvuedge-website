19499 Unlisted procedure breast

Surgery

Also known as: unlisted breast procedure

Unlisted surgical procedure of the breast for procedures not specifically described by other current procedural terminology codes. This code captures novel or uncommon breast procedures.

In Plain Language

a breast operation not covered by standard codes

Clinical Context

Used for new or unusual breast procedures not fitting existing codes. Requires detailed operative report describing procedure, indications, and findings.

RVU Information

CPT 19499 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
