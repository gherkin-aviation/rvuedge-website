38792 Ra tracer id of sentinl node

Surgery Global 0d

Also known as: Sentinel node identification, Radioisotope localization

Injection of radioactive tracer for identification of sentinel lymph nodes using radionuclide imaging.

Clinical Context

Used in sentinel lymph node biopsy for melanoma, breast cancer, and other solid tumors to guide surgical removal.
