15111 Epidrm agrft t/a/l each additional

Surgery +Add-on

Also known as: epidermal graft additional, epidermal add-on

Epidermal autograft applied to trunk, arms, or legs, each additional 100 square centimeters beyond the first. Add-on code for extended epidermal coverage.

Clinical Context

Used for extended epidermal coverage when initial 100 square centimeters is insufficient for large partial thickness burn areas.
