19086 Biopsy breast add lesion mr imag

Surgery +Add-on

Also known as: MRI breast biopsy add-on, MR imag biopsy add-on

Percutaneous needle or core biopsy of breast lesion under magnetic resonance imaging guidance for each additional lesion.

Clinical Context

Add-on code for multiple MRI-guided biopsies in same session. Each additional lesion requiring guidance coded separately.
