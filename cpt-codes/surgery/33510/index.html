33510 Cabg vein single

Surgery Global 90d

Also known as: single vein CABG, single SVG bypass, single vessel CABG

Surgical placement of a single coronary artery bypass graft using saphenous vein conduit, the base code for isolated single vessel bypass.

Clinical Context

Indicated for single significant coronary stenosis causing symptomatic angina or objective ischemia; provides improved survival and symptom relief compared to medical therapy alone.
