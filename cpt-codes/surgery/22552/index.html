22552 Arthrd anterior ntrbd cervical each

Surgery +Add-on

Also known as: ACDF add-on, Additional anterior cervical fusion

Arthrodesis, anterior/anterolateral approach, including discectomy and/or corpectomy, cervical; each additional interspace.

Clinical Context

Add-on code for multi-level anterior cervical fusion; used when pathology spans multiple intervertebral levels.
