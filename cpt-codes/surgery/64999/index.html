64999 Unlisted procedures nervous system

Surgery

Also known as: unlisted nerve procedure, unlisted neurosurgery

Unlisted code for any peripheral nervous system procedure not otherwise classified by specific Current Procedural Terminology codes. Used for novel or unusual procedures.

In Plain Language

nerve surgery not listed in standard codes

Clinical Context

Used when a legitimate peripheral nervous system surgical procedure does not fit into existing CPT codes. Requires documentation of procedure and relative value justification.

RVU Information

CPT 64999 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
