11103 Tangntl biopsy skin each sep/additional

Surgery +Add-on

Also known as: additional shave biopsy, tangential biopsy each

Tangential biopsy of skin for each separate or additional lesion using horizontal shaving technique. This is an add-on code for evaluating multiple lesions with the same biopsy approach.

Clinical Context

Applied when patient has multiple suspicious lesions requiring biopsy evaluation in the same session. Each additional lesion beyond the first uses this add-on code.
