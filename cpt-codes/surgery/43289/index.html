43289 Unlisted laps procedures esophageal

Surgery

Also known as: unlisted lap esophageal procedure, unlisted esophageal laparoscopy, unlisted lap stomach procedure

Unlisted laparoscopic procedure of the esophagus. This code is used for novel laparoscopic esophageal procedures not described by other CPT codes.

In Plain Language

other camera surgery on esophagus; unlisted esophageal procedure

Clinical Context

Appropriate for experimental or novel laparoscopic techniques; requires detailed operative report for billing and medical necessity documentation.

RVU Information

CPT 43289 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
