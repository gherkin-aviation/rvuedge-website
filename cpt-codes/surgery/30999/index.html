30999 Unlisted procedure nose

Surgery

Also known as: unlisted nasal procedure, unspecified nose surgery, other nasal procedure

Unlisted or miscellaneous procedure of the nose and nasal passages, used for procedures not otherwise classified by specific CPT codes.

In Plain Language

other nasal surgery

Clinical Context

Used for novel, experimental, or unusual nasal procedures without dedicated code. Requires detailed operative report documenting medical necessity and complexity.

RVU Information

CPT 30999 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

As a surgical CPT code, proper documentation must include the operative report detailing the procedure performed, patient positioning, approach, findings, and any complications. Ensure the diagnosis code (ICD-10) supports medical necessity for the procedure.
