64913 Nerve repair with nerve algrft each additional

Surgery +Add-on

Also known as: additional allograft segment

Add-on code for each additional nerve allograft segment required beyond the first allograft in repair of extensive nerve injuries.

Clinical Context

Used when multiple allograft segments required for extensive gap repair. Each segment after the first is coded with this add-on code.
