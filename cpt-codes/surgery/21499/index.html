21499 Unlisted musculoskeletal procedures head

Surgery

Also known as: unlisted head musculoskeletal procedure, head surgery not otherwise specified

Unlisted musculoskeletal procedure on the head. This code represents any musculoskeletal procedure on the head region not specifically described by other current procedural terminology codes.

Clinical Context

Used for head musculoskeletal procedures not captured by more specific codes. Requires detailed documentation for medical record review board assessment. Should not be used if more specific code exists.
