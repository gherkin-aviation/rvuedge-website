63048 Lam facetec &foramot each additional

Surgery +Add-on

Also known as: cervical laminectomy, facetectomy, foraminotomy extension, laminectomy additional level

Laminectomy with facetectomy and foraminotomy for each additional segment. This is an add-on code used when the cervical laminectomy involves extending the decompression to additional vertebral levels.

In Plain Language

spinal canal enlargement extension; nerve root opening at additional levels

Clinical Context

Used as an add-on code when cervical myelopathy or radiculopathy requires decompression beyond the primary levels, typically performed for symptomatic stenosis at multiple segments.
