22116 Remove extra spine segment

Surgery +Add-on

Also known as: additional vertebral segment ostectomy with decompression, per additional level ostectomy decompression

Partial ostectomy of each additional vertebral segment with decompression. Each additional vertebra requiring ostectomy with significant decompression beyond the first segment.

Clinical Context

Used as add-on code for each additional vertebra requiring ostectomy with significant decompression in multilevel procedures. Typically appended to primary ostectomy codes.
