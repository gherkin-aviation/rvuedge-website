15136 Drm agrft f/s/n/h/f/g/m each

Surgery +Add-on

Also known as: facial dermal graft additional, specialized dermal add-on

Dermal autograft applied to face, scalp, neck, hands, feet, genitals, or mucosal surfaces, each additional area. Add-on code for multiple specialized regions.

Clinical Context

Used for complex facial injuries or burns affecting multiple anatomical regions requiring dermal replacement.
