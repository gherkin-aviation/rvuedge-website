19001 Puncture aspiration cyst brst each

Surgery +Add-on

Also known as: breast cyst aspiration add-on, additional cyst aspiration

Percutaneous needle aspiration and cytology of each additional breast cyst beyond the first during same session.

Clinical Context

Add-on code for aspiration of multiple cysts in same breast during single procedure. Each additional cyst coded separately.
