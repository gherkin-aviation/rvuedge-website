4051F Referred for an av fistula

Other

Also known as: AV fistula referral, vascular access referral

Performance measure indicating documentation that patient was referred for an arteriovenous fistula. Tracks referral for vascular access creation.

In Plain Language

referral to create a blood vessel access

Clinical Context

Quality measure for chronic kidney disease patients on or approaching dialysis. AV fistulas are preferred vascular access for hemodialysis.

RVU Information

CPT 4051F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
