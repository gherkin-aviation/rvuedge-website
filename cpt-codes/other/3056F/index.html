3056F Lvef greater than 35%

Other

Also known as: LVEF >35% documented, better EF documented, preserved systolic function documented

Documentation of left ventricular ejection fraction (LVEF) greater than 35%, indicating better-preserved systolic function.

In Plain Language

better heart pumping documented

Clinical Context

Quality measure code documenting improved or less severely reduced systolic function; indicates better prognosis compared to more advanced dysfunction.

RVU Information

CPT 3056F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
