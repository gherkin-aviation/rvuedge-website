1091F Urine incon characterized

Other

Performance measure documenting that urinary incontinence was characterized, including type classification and severity assessment.

In Plain Language

Incontinence type identified; Bladder problem characterized

Clinical Context

Quality measure ensuring classification of incontinence type (stress, urge, overflow, mixed) to guide treatment selection.

RVU Information

CPT 1091F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
