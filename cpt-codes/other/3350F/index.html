3350F Mammo biopsy proven malignant docd

Other

Also known as: breast biopsy documented malignancy, mammography malignancy confirmation, cancer documentation code

Clinical performance measure documenting that mammographic biopsy has proven malignancy with pathologic confirmation recorded in the medical record.

In Plain Language

breast biopsy confirmed cancer

Clinical Context

Quality measure code used to document that a suspicious breast finding on mammography has been confirmed as malignant through biopsy pathology; essential for cancer staging and treatment planning.

RVU Information

CPT 3350F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
