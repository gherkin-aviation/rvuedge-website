2015F Asthma impairment assessed

Other

Also known as: asthma impairment assessed, asthma severity documented

Performance measure for documentation of asthma impairment assessment using standardized tools or questionnaires. This metric tracks severity and functional limitation evaluation.

In Plain Language

asthma severity and symptoms checked

Clinical Context

Used as quality measure for asthma management to ensure assessment of symptom frequency, nighttime symptoms, and functional limitations using validated assessment tools.

RVU Information

CPT 2015F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
