3720F Cognit impairment assessed

Other

Also known as: cognitive screening, cognition assessment, dementia screening

Documentation that the patient's cognitive impairment has been assessed and documented, often using validated cognitive screening instruments.

In Plain Language

memory and thinking test; cognitive evaluation

Clinical Context

Quality measure for elderly patients or those with neurological conditions. Early detection important for disease management and caregiver planning.

RVU Information

CPT 3720F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
