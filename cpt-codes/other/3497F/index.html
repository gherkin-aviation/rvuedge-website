3497F Cd4+ cell percentage <15%

Other

Also known as: CD4 percentage < 15%, CD4 percent low

CD4+ cell percentage less than 15% of total lymphocytes in HIV patients. Performance measure code for relative immunosuppression.

In Plain Language

immune cells less than 15% of white blood cells

Clinical Context

Quality measure using percentage-based CD4 assessment, particularly useful in infants and when absolute counts unavailable.

RVU Information

CPT 3497F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
