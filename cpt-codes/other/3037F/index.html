3037F O2 saturation >88%/pao>55 hg

Other

Also known as: adequate oxygenation documented, O2 sat >88% documented, normal oxygen documented

Documentation of oxygen saturation measured greater than 88% OR partial pressure of arterial oxygen (PaO2) greater than 55 mmHg.

In Plain Language

adequate oxygen level documented

Clinical Context

Quality measure code documenting adequate oxygenation; indicates respiratory function is preserved without significant hypoxemia.

RVU Information

CPT 3037F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
