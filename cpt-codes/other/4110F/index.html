4110F Int mam artery used for cabg

Other

Also known as: CABG with internal mammary, IMA graft measure, internal thoracic artery measure

Performance measure code indicating that internal mammary artery was used for coronary artery bypass grafting.

In Plain Language

artery used for heart surgery; chest artery heart graft; quality heart surgery measure

Clinical Context

Quality measure for coronary artery bypass grafting indicating use of internal mammary (thoracic) artery, which has superior long-term patency compared to saphenous vein.

RVU Information

CPT 4110F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
