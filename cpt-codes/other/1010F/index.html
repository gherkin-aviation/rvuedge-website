1010F Severity angina by actvty

Other

Performance measure documenting assessment of angina severity classification by activity level, including grading of exercise tolerance.

In Plain Language

Chest pain severity by activity; Angina grade by exercise

Clinical Context

Quality measure for cardiac patients using Canadian Cardiovascular Society or similar grading to document angina severity and response to therapy.

RVU Information

CPT 1010F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
