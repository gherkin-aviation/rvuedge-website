1118F Gerd symps assessed 12 month

Other

Also known as: GERD assessment code

Documentation that gastroesophageal reflux disease symptoms have been assessed within a 12-month period. This is a quality measure code tracking symptom monitoring.

Clinical Context

Used to document periodic assessment of reflux symptoms in patients with diagnosed GERD to track disease control and treatment effectiveness.

RVU Information

CPT 1118F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
