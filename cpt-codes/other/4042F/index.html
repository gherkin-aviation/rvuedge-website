4042F Doc antibio not given

Other

Also known as: antibiotic not given, prophylaxis withheld

Performance measure indicating documentation that appropriate antibiotics were not given when contraindicated. Records absence of unnecessary prophylaxis.

In Plain Language

appropriately not giving antibiotics

Clinical Context

Quality measure for appropriate antibiotic stewardship. Documents cases where prophylaxis is correctly omitted (e.g., very low-risk procedures or allergies).

RVU Information

CPT 4042F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
