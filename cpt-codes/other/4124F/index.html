4124F Antibiot not rxd/given

Other

Also known as: no antibiotic measure, antibiotic not prescribed, appropriate antibiotic restraint

Performance measure code indicating that antibiotic medication was not prescribed or given in an appropriate clinical setting.

In Plain Language

no infection medication needed; antibiotic not given appropriately; no antibiotic treatment

Clinical Context

Quality measure for appropriate antibiotic stewardship. Tracks cases where antibiotics are appropriately withheld, such as viral upper respiratory infections.

RVU Information

CPT 4124F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
