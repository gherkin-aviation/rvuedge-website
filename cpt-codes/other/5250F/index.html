5250F Asthma discharge plan presnt

Other

Also known as: asthma discharge documentation

Performance measure code documenting that an appropriate asthma discharge plan was provided to the patient upon hospital discharge.

In Plain Language

asthma care plan documentation

Clinical Context

Quality reporting measure for asthma management. Not a billable procedure; used for regulatory and quality assessment.

RVU Information
