1111F Dschrg medial/current medial merge

Other

Also known as: med reconciliation code

Documentation of discharge medications or current medication list merged and reconciled. This performance measure code tracks medication reconciliation at discharge.

Clinical Context

Used to report that discharge medications have been documented and compared with current outpatient medication list to ensure accuracy and prevent drug errors.

RVU Information

CPT 1111F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
