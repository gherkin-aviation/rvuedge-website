4136F Syst corticosteroids not prescription

Other

Also known as: no systemic corticosteroid measure, systemic steroid not given, steroid restraint

Performance measure code indicating that systemic corticosteroid medication was not prescribed or was appropriately withheld.

In Plain Language

no inflammation steroid given; systemic steroid not used; no oral steroid

Clinical Context

Quality measure documenting appropriate steroid stewardship. Tracks cases where systemic corticosteroids are appropriately not used.

RVU Information

CPT 4136F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
