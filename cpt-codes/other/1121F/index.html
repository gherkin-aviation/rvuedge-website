1121F Subs evaluation for condition

Other

Also known as: subsequent eval code

Documentation of subsequent evaluation for patient's medical condition. This performance measure code tracks follow-up visit assessment and documentation.

Clinical Context

Used to report that comprehensive subsequent evaluation and reassessment has been documented for ongoing patient care or established diagnosis.

RVU Information

CPT 1121F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation
