4025F Inhaled bronchodilator prescription

Other

Also known as: bronchodilator therapy, rescue inhaler

Performance measure indicating documentation that inhaled bronchodilator therapy was prescribed. Tracks acute symptom relief medication for obstructive airway disease.

In Plain Language

quick-relief inhaler for breathing

Clinical Context

Quality measure for asthma and COPD. Includes short-acting beta-agonists (albuterol) for acute symptom relief.

RVU Information

CPT 4025F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
