1116F Auric/peri-procedural pain assessed

Other

Also known as: ear pain assessment code

Documentation that auricular or periauricular pain has been assessed. This performance measure code tracks pain assessment in patients with ear or surrounding area pain.

Clinical Context

Used to document pain evaluation in conditions affecting the ear or area around the ear including otitis, temporomandibular joint disorder, and auricular trauma.

RVU Information

CPT 1116F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
