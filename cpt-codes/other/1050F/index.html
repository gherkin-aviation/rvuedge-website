1050F History of mole changes

Other

Performance measure documenting patient history of changes in moles or skin lesions, including documentation of concerning characteristics.

In Plain Language

Mole change history; Skin lesion change assessment

Clinical Context

Quality measure for melanoma screening, documenting baseline mole characteristics and any patient-reported changes over time.

RVU Information

CPT 1050F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
