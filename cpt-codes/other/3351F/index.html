3351F Neg screening dep symp by deptool

Other

Also known as: negative depression screening, depression screen negative, normal depression tool

Clinical performance measure documenting that depression screening was performed and resulted in negative (normal) findings using a validated depression assessment tool.

In Plain Language

mental health screening came back normal

Clinical Context

Quality metric used in primary care and behavioral health settings to document that appropriate depression screening was conducted using standardized instruments (PHQ-9, PHQ-2) with normal results.

RVU Information

CPT 3351F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
