Other

Also known as: inpatient discharge code

Documentation that patient left inpatient facility within 60 days. This is a performance measure tracking code for transitions of care metrics.

Clinical Context

Used as a quality measure to document patient discharge from hospital or inpatient setting within 60-day window. Supports care transition and continuity documentation.
