3218F Rna tstng hep c docd done

Other

Also known as: Hepatitis C RNA testing documented, HCV RNA testing

Performance measure documenting that Hepatitis C ribonucleic acid (RNA) testing has been documented as ordered or completed, used to track screening protocols.

In Plain Language

hep C virus test done

Clinical Context

Used as a quality measure to document appropriate screening or diagnostic testing for Hepatitis C virus RNA in patients with risk factors or known exposure.

RVU Information

CPT 3218F does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.
