96376 treatment/pro/diagnosis injection same drug adon

Medicine +Add-on

Also known as: same drug add-on, repeat dose add-on

Therapeutic, prophylactic, or diagnostic injection of same drug or agent administered more than once, as add-on code.

Clinical Context

Add-on code for additional doses of same medication when multiple administrations occur during same session.
