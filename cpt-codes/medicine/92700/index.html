92700 Unlisted orl service/procedures

Medicine

Also known as: unlisted ENT service, unlisted otolaryngology

Unlisted otorhinolaryngologic (ear, nose, throat) service or procedure performed when no specific code adequately describes the service.

Clinical Context

Used when a legitimate otorhinolaryngologic service is provided that does not have a specific CPT code available, requiring detailed documentation of the procedure or service.
