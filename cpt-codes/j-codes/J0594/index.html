J0594 Busulfan injection

J-Codes

Also known as: busulfan, Busulfex, alkylating agent

Busulfan injection for intravenous administration, an alkylating agent chemotherapy drug used in conditioning regimens for hematopoietic stem cell transplantation.

Clinical Context

Used as myeloablative conditioning agent prior to hematopoietic stem cell transplantation for chronic myeloid leukemia and other hematologic malignancies. Administered via central line with intensive supportive care.
