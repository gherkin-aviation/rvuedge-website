J3490 Drugs unclassified injection

J Codes (Drugs)

Also known as: unclassified drug, unlisted injection

Drugs, unclassified injection is a catch-all code for injectable drugs not specifically coded elsewhere in HCPCS.

In Plain Language

miscellaneous medication injection

Clinical Context

Used when a specific injectable drug lacks a dedicated code. Requires documentation of drug name, dose, and route. Used temporarily until specific code assignment or for rare medications.

RVU Information

CPT J3490 does not have a physician work RVU assigned by CMS. This is typical for supply, drug, and equipment codes — reimbursement is based on Average Sales Price (ASP), fee schedules, or payer contracts rather than the RVU system.

Billing & Documentation

J-codes represent drugs administered by a healthcare provider (not self-administered). Documentation must include the drug name, dosage, route of administration, and medical necessity. Most payers require the National Drug Code (NDC) on the claim. Bill the appropriate administration code (96365-96379) in addition to the drug code.
