J3490 Drugs unclassified injection

J-Codes

Also known as: unclassified drug, unlisted injection

Drugs, unclassified injection is a catch-all code for injectable drugs not specifically coded elsewhere in HCPCS.

Clinical Context

Used when a specific injectable drug lacks a dedicated code. Requires documentation of drug name, dose, and route. Used temporarily until specific code assignment or for rare medications.
