J3535 Metered dose inhaler drug

J-Codes

Also known as: MDI, metered dose inhaler, inhaler

Metered dose inhaler drug is a pressurized inhaler containing therapeutic agents for bronchial delivery.

Clinical Context

Generic code for medications delivered via metered dose inhaler. Used for bronchodilators, corticosteroids, and other respiratory medications. Requires patient instruction for proper technique.
