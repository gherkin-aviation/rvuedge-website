Radiology +Add-on

Also known as: CT-FFR, fractional flow reserve, computational flow analysis

Non-invasive determination of coronary fractional flow reserve using computed tomography angiography and computational analysis for functional stenosis assessment.

Clinical Context

Determines hemodynamic significance of coronary stenosis non-invasively using computational fluid dynamics; guides revascularization decisions.
