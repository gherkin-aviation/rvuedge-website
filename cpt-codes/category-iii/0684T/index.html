0684T Peri-px device evaluation implantable subcutaneous defibrillator sensing system inpatient

Category III

Also known as: ISDSS perioperative evaluation

Peri-procedural device evaluation of insulin-dependent diabetes management system with in-person assessment. This Category III code represents perioperative device evaluation.

Clinical Context

Used for assessment of insulin delivery systems during perioperative period to ensure appropriate function and adjustment.
