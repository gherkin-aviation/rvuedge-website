0621T Trabeculostomy interno laser

Category III

Also known as: Trabeculostomy laser

Trabeculostomy using internal laser application without endoscopic visualization. This Category III code represents laser-assisted creation of trabecular outflow.

Clinical Context

Used for glaucoma management to improve aqueous outflow through trabecular meshwork via internal laser technique.
