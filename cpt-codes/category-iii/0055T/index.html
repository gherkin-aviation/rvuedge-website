0055T Bone srgry cmptr CT/MRI imag

Category III +Add-on

Also known as: computer-assisted navigation CT/MRI, surgical navigation CT-based

Computer-assisted musculoskeletal surgical navigational tracking procedure using CT or MRI images for bone surgery. This is a Category III code for emerging technology involving preoperative cross-sectional imaging-based computer navigation.

Clinical Context

Used for computer-assisted surgical navigation that uses preoperative CT or MRI images registered to the patient for intraoperative guidance during bone surgery. Provides 3D navigation without intraoperative radiation exposure from fluoroscopy.
