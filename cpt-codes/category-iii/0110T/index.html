0110T not otherwise specified quantitative sensory test

Category III

Also known as: QST other modality, sensory threshold testing NOS

Quantitative sensory testing (QST) using other stimuli not otherwise specified to assess sensory thresholds. Category III code for standardized psychophysical testing using stimuli not covered by 0106T-0109T.

Clinical Context

Used for quantitative sensory testing using stimuli modalities other than touch, vibration, cooling, or heat-pain. May include current perception threshold testing, temporal summation testing, or other standardized psychophysical testing paradigms.
