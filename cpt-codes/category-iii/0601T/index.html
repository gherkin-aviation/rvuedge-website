0601T Ablation ire 1+tumors open

Category III

Also known as: Open prostate IRE ablation

Ablation of one or more malignant tumors of the prostate using irreversible electroporation via open surgical approach. This Category III code represents surgical ablation with electroporation technology.

Clinical Context

Used for open surgical ablation of prostate tumors using irreversible electroporation when percutaneous approach is not feasible or multiple lesions require treatment.
