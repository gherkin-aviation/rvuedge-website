D3426 Root surgery each add root

D-Codes +Add-on

Also known as: additional root surgery, extra root removal, extra apical surgery

Each additional root surgical removal from a multi-rooted tooth in apical surgery.

Clinical Context

Separate reportable procedure for each additional root treated during multi-rooted tooth apical surgery. Common in molar apicoectomy procedures.
