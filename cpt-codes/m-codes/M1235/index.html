M Codes

Documented hepatitis C virus antibody positive and hepatitis C ribonucleic acid testing performed.

In Plain Language

Hepatitis C virus level test done; Viral load testing for hepatitis C

Clinical Context

Hepatitis C quality measure documenting hepatitis C viral RNA testing for confirmation and virologic assessment in HCV-antibody-positive patients.

RVU Information
