M0235 Intrav inferior, mon anti, fir do

M Codes

Also known as: monoclonal antibody infusion first dose, initial antibody infusion

Intravenous Infusion Monoclonal Antibody First Dose. Reporting code for initial monoclonal antibody infusion administration.

In Plain Language

first antibody injection; initial immunotherapy infusion

Clinical Context

Used for reporting first infusion of monoclonal antibodies in treatment sequence, establishing baseline for dosing.

RVU Information

CPT M0235 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation
