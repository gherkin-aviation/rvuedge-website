M Codes

Quality Care for Neurologic Conditions Model Value-Based Payment Arrangement. Reporting code for neurology specialty value-based services.

In Plain Language

neurological care value payment; quality-based payment model

Clinical Context

Reporting code for neurology practices participating in Centers for Medicare and Medicaid Services value-based models for neurologic conditions.

RVU Information

CPT M0004 does not have a physician work RVU assigned by CMS. Reimbursement for this code is determined by payer-specific fee schedules.

Billing & Documentation

M-codes cover quality measures and performance reporting. They are used in value-based care programs to track whether specific clinical actions were taken. Documentation must support that the measured action was performed or a valid exclusion applies.
